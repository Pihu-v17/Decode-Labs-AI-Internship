# DecodeLabs — Artificial Intelligence Internship

This repository contains the projects completed as part of my **Artificial Intelligence Internship at DecodeLabs**.

The internship focused on progressively building practical skills in **Python, Artificial Intelligence, Machine Learning, Recommendation Systems, Computer Vision, and OCR**.

---

## 🚀 Projects

### Project 1 — Rule-Based AI Chatbot

A basic rule-based conversational chatbot developed using Python.

**Key Concepts:**
- Rule-based AI
- `if-else` control flow
- User input handling
- Predefined responses
- Continuous conversation loop
- Input sanitization
- Fallback responses

**Technologies:**
- Python

---

### Project 2 — Data Classification Using AI

A supervised machine learning classification model developed using the **Iris dataset**.

**Key Concepts:**
- Data preprocessing
- Train/test split
- Feature scaling
- K-Nearest Neighbors (KNN)
- Model evaluation
- Confusion matrix
- F1 score
- Classification report

**Technologies:**
- Python
- Scikit-learn
- KNN
- StandardScaler

**Model Performance:**
- Accuracy: **93.33%**
- Weighted F1 Score: **0.93**

---

### Project 3 — AI Recommendation Logic

A **Tech Stack Recommender** that recommends suitable career paths based on the user's skills.

**Key Concepts:**
- User preference matching
- TF-IDF vectorization
- Cosine similarity
- Similarity scoring
- Ranking
- Top-N recommendations

The system takes user skills as input, compares them with predefined career-role profiles, and generates the **Top 3 recommended career paths**.

**Technologies:**
- Python
- Scikit-learn
- TF-IDF
- Cosine Similarity

---

### Project 4 — Image / Text Recognition

A basic **OCR (Optical Character Recognition)** pipeline for extracting text from images.

**Key Concepts:**
- Image preprocessing
- Grayscale conversion
- Gaussian blur
- Adaptive thresholding
- Image deskewing
- OCR
- Confidence-based validation

**Technologies:**
- Python
- OpenCV
- NumPy
- Pytesseract
- Tesseract OCR
